# 🫀 Cardiac Science Research Project Website

A high school research project website featuring cardiac science, medical terminology, and CRISPR genetic editing research.

## ✨ Features

- **3D Animated Beating Heart** - Interactive Three.js visualization on homepage
- **Medical Terminology** - Comprehensive glossary of cardiac terms
- **CRISPR Research** - Complete guide to genetic editing in cardiac medicine
- **Photo Gallery** - Showcase your research images
- **Resources** - Educational links and research materials
- **Responsive Design** - Works on mobile, tablet, and desktop
- **Easy to Update** - Simple HTML files you can edit directly
